# 前端体验重整

## 范围与约定

用户要求使用 ask-matt、emil-ask-emil、CQU Moe Design 全面优化前端，选择整体体验均衡优化，并明确允许重写。后续要求移除页面版本号及更新日志，操作栏文字按钮与图标按钮必须等高。

保留登录回跳、现有 URL（已移除的更新日志除外）、接口、权限与订阅同步规则；外部课表继续处于暂不可用状态。依赖以项目内 theme/ui 1.1.0 tarball 的公开契约为准。

## 页面设计

- 首页：一个开始使用入口、订阅三步指南、支持的日历与服务能力；无虚构课表、统计或用户数据。
- 业务外壳：共享 AppShell 桌面侧栏、手机导航抽屉、主题与账户菜单；页面切换管理焦点。
- 我的订阅：状态和额度集中展示，课表信息与操作并列；手机把查看/复制与同步/二维码/更多分为两行；按钮使用配对 default/icon 尺寸。
- 添加订阅：明确返回入口，区分登录/订阅列表加载失败和真正空数据；失败可重试，未知状态阻止重复创建。
- 课表：独立品牌顶栏和紧凑宽内容区，无桌面侧栏或手机导航抽屉；标题与学期/教学周信息并排，移除叠加的顶部留白并保留适量呼吸空间。日周月切换使用表面色按钮和细下划线选中态；保留主题、账户、事件详情、键盘操作、空状态和失败恢复。
- 使用与 API：先说明如何订阅，再解释链接与公开接口。

## 验证方式

构建与设计检查：在 frontend 执行 `pnpm build`、`pnpm check:design`。
交互测试：`pnpm test`。

本地浏览器验收使用独立固定数据服务：

```sh
node frontend/scripts/preview-fixtures.mjs
# 另一个终端，在 frontend 中：
pnpm dev --port 5178
```

固定数据服务只监听 127.0.0.1:8787，不属于生产入口。`/view/preview`、`/view/empty`、`/view/missing`、`/view/forbidden` 分别为正常、空日程、404、403。PUT 本地服务 `/__scenario`，JSON `{ "scenario": "error" }` 可切换失败，`ready` 恢复，`empty` 清空订阅，`guest` 为未登录。

浏览器固定数据通过不等于真实认证、教务同步、Cloudflare 部署或真机通过。真实接口、iOS Safari、Android 与屏幕阅读器验收单独记录。

## 本地验收结果（2026-10-12）

- 前端完整回归：22 个文件、182 项测试通过；TypeScript、生产构建、设计规则检查和 `git diff --check` 通过。
- 浏览器：5 个页面 × 浅色/深色 × 320/390/768/1440px，共40组视图，未发现页面横向溢出。
- 订阅操作：桌面文字/图标按钮均为40px；模拟粗指针触屏均为44px，手机分两行排列。
- 用户追加视觉反馈后，类型标签去掉灰色填充，学期改为普通元信息，「查看课表」改用共享主按钮变体；订阅页重新检查两种主题与4种宽度，15项订阅页测试、构建及设计检查通过。
- 课表紧凑布局与工具栏调整后，重新检查浅色/深色与320/390/768/1440px，均无页面横向溢出。课表与路由共18项测试、TypeScript、生产构建和设计检查通过。
- 键盘：课程可用 Enter/Space 打开，Escape 关闭后回到课程；二维码和共享链接弹窗回到对应触发按钮；手机抽屉导航后正文获得焦点。
- 恢复路径：订阅加载失败与重试、空订阅、添加页未知订阅状态与重试、课表请求失败与重试、空课表、403和404均通过固定数据浏览器检查。
- 未登录入口保留 `returnTo`；开始使用仍转到 `/dashboard?setup=1`。减少动画偏好下，课表详情无运行中的动画。
- 相同无 PostHog token 的构建环境，入口与静态预加载 JS 合计从864.03KB降到580.90KB（gzip从277.54KB降到184.22KB）。已合计新的 `auth` 静态预加载块；这些是构建体积，不代表真实网络加载时长。二维码和共享管理按需加载；配置 PostHog 时 SDK 单独加载。

代码审阅未留下高置信未解决问题。以上为本地验收记录，固定数据预览不代表真实账号业务验收或生产部署验证。

## 设计系统反馈

UI 1.1.0 的 `sm` 文字按钮（32px）和 `icon-sm` 图标按钮（40px）不等高。此次通过公开 `default`/`icon` 尺寸统一为40px，触屏沿用共享44px规则，未修改共享包。建议共享包未来明确小尺寸文字与图标按钮的配对规则。

二维码图像使用白色背景保留扫描对比度；其他业务表面使用主题 token。FullCalendar 自带的结构和交互采用现有集成样式适配，不覆盖 `.ds-*` 共享控件内部样式。

按用户明确要求，课表预览采用紧凑的业务标题和容器布局：UI 1.1.0 的 PageHeader / ContentContainer 没有密度选项，原有外层与组件内边距会叠加。此页使用语义 header/main、共享宽度/字号/间距 token，保留共享主题、按钮及浮层；若共享包提供紧凑布局 API，可改回公开组件组合。
