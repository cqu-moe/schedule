## Parent

[规格 #133](https://github.com/cqu-moe/schedule/issues/133)

## What to build

以已研究过的行政班为首条搜索路径，贯通学校正常页面动作、Auth 受限搜索能力、Schedule 搜索入口和目标选择界面。用户看到的是学校当前学期及可区分的真实目标。

## Acceptance criteria

- [ ] 有外部准入权益和有效学校绑定的用户能按院系、年级和关键词搜索行政班；候选包含稳定身份及必要区分信息。
- [ ] 当前学期来自正常学校页面或受支持的同会话上下文；不根据月份猜测，不采集个人课表取学期，不接受客户端指定历史学期。
- [ ] Auth 检查服务身份、获批方法、子系统、目标用户、外部权益与学校绑定；只接受固定业务参数，不接受任意 URL、选择器、HTTP 方法或请求体。
- [ ] 学校页面权限和禁用控件保持原状；只捕获本次目标搜索预期的响应。Cookie、Bearer、浏览器存储和防护密文不进入 Schedule 或日志。
- [ ] 空结果、结果可能被截断、目标无权查看、学校会话失效、浏览器忙碌和服务不可用分别表达；不能把截断结果称作完整目录。
- [ ] 搜索缓存按用户、来源、当前学期、关键词和过滤条件隔离，短期有效；命中缓存前仍检查准入。
- [ ] 未支持的来源和学生个人查询明确拒绝；搜索流程不创建订阅或扣手动次数。新 RPC 未部署或未获批时明确不可用，无旧 HTTP/个人采集回退。
- [ ] 通过 Auth RPC 与 Schedule 搜索入口验证拒绝路径、缓存隔离和返回合同；完成行政班登录实测，并验证键盘、窄屏和加载/错误状态。
