## What to build

完成课程到教学班的两步选择及当期首次采集，锁定教学班身份和当前学期。该类型接入统一外部任务，学校切学期的禁用与恢复流程由后续两票完成后才可对外开放。

## Acceptance criteria

- [ ] 先搜索课程，再查询该课程当前学期教学班；候选有足够班次区分信息，不把课程目录 ID 当成教学班 ID，也不默认订阅整门课程。
- [ ] 创建时学校当前学期与已选教学班必须一致；选择期间学期发生变化需重新选择，不接受历史学期或客户端伪造的当前上下文。
- [ ] 正常学校页面触发普通课和实验项目所需全部响应；按教学班 ID 校验归属，不将其他教学班的数据合并。
- [ ] 普通课和实验独立表达且均进入日历；按可验证的项目、时间、地点等区分事件，同名不误删，不因重复响应生成重复安排。
- [ ] 缺少必需捕获、响应结构不合法、目标不匹配是整体失败并保留旧结果；可跳过的单条信息不足才显示部分导入与数量。
- [ ] 保存创建学期，后续任务只能为预期学期和教学班写入；发现当前学期变化时拒绝继续采集旧班，不自行匹配同名课程。
- [ ] 通过两步选择、创建、后台结果、主人状态及公开日历验证完整路径；已登录取得包含实验的真实教学班样例并逐项比对，覆盖多班混合响应。
- [ ] 在过期禁用及原链接重选任务完成前，教学班仅供受控验证，不提前开放缺少生命周期的公共功能。
