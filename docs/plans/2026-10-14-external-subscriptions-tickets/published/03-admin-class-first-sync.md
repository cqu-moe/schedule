## Parent

[规格 #133](https://github.com/cqu-moe/schedule/issues/133)

## What to build

完成第一条新外部订阅的纵向链路：用户选定当前学期行政班后创建，后台通过 Auth 正常页面捕获、校验目标并生成课表，最终从现有公开订阅链接读取。以既有队列、运行标识和日历机制为基础，只抽取此链路确实需要的外部采集分支。

## Acceptance criteria

- [ ] 新记录有明确来源版本，贯穿去重、队列、采集和写入；旧记录、旧任务继续冻结且绝不进入新采集或个人采集，不删除旧数据。
- [ ] 旧外部记录不占新外部配额、不因同目标或旧唯一约束阻挡新建；数据库约束与界面重复提示保持一致。
- [ ] 覆盖相关问题 #103：系统管理的默认个人行不挤占用户可创建的外部配额，sub_limit=1 且具备准入的用户可创建一条新外部订阅；不给用户额外补授权益。本任务不自动关闭 #103。
- [ ] 提交后立即返回持久化订阅和首次同步状态，用户离开页面仍继续；失败保留订阅及可解释错误。首次采集不扣手动次数，且不要求另有自动或手动权益。
- [ ] 首次取得可用结果前不把占位空日历标成成功；合法空课表与首次失败不同，合法空结果可以成为成功快照。
- [ ] 使用行政班嵌套教学对象校验每行归属；普通课、实验及其他活动仅在名称、时间和归属可验证时导入。可跳过的不可解析条目计数并显示部分导入，非法整体响应、缺少必需捕获或目标不匹配则失败。
- [ ] 完整、部分、合法空、失败有不同状态；失败保留上次可用数据，重复消息不重复生成安排。可用结果通过现有日历输出正常读取，事件身份稳定。
- [ ] 同一订阅的重复任务复用在途运行；结果只写入匹配的版本、运行、目标学期和生命周期。删除、撤权、解绑或目标变化使旧响应无效。
- [ ] 限制同用户浏览器并发并使用有限重试；学校会话/权限错误不无限重试。准入撤销和分享链接仍沿用既有各自授权规则，不停止权限对账。
- [ ] 通过创建入口、队列入口、主人状态与公开日历验证闭环及真实 D1 的新旧冲突场景；完成一个已登录行政班的输出比对，明确区分本地和现场证据。
