## Parent

[规格 #133](https://github.com/cqu-moe/schedule/issues/133)

## What to build

接入实验室专用页面动作及响应规则，沿完整外部订阅链路生成实验室日历；不能因为同样存在房间 ID 就未经验证照搬教室入口。

## Acceptance criteria

- [ ] 实验室候选能准确区分场地，选择稳定身份；独立验证该类型页面、过滤条件及预期捕获。
- [ ] 按所选房间 ID 校验实验室课表归属，实验项目名称、时间和地点来自可验证字段，不从课程名猜测实验信息。
- [ ] 异步首次采集和日历读取可演示；合法空、失败、部分导入有不同结果，重复刷新不会把不同实验误合并或制造重复。
- [ ] 共用新外部订阅的权限、任务、当前学期和数据完整性合同；接入统一 provider，支持后续手动与自动采集。
- [ ] 以独立脱敏样例证明实验与普通课区分、归属及缺字段处理；完成已登录实验室搜索、选择、创建及日历比对，记录真实能力边界。
