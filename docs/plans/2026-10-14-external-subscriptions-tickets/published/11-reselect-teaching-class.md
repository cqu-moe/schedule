## Parent

[规格 #133](https://github.com/cqu-moe/schedule/issues/133)

## What to build

落实用户最新补充：过期不是必须新建。主人在现有过期教学班订阅上搜索并选择当前教学班，后台完成新学期首次采集后恢复服务，原订阅身份与全部链接地址保持不变。

## Acceptance criteria

- [ ] 只有订阅主人且仍具备外部准入和有效学校绑定才能操作；沿课程到教学班的选择流程，只选可信当前学期目标。
- [ ] 保留订阅 ID、默认链接及额外分享链接地址/令牌；更新目标和学期不创建新订阅、不额外占订阅数量，不批量轮换链接。
- [ ] 重选作为新目标的首次采集，按首次采集规则不扣手动次数，不要求自动间隔；仍受既有冷却、限流和同用户浏览器容量约束。
- [ ] 提交后显示重新同步中，在新目标取得可用结果前公共链接保持停用，不把旧教学班快照当成新班结果发布。
- [ ] 取得完整、合法空或带明确完整性信息的可用新结果后，以一致状态替换目标、结果和生命周期，再恢复相同公开地址；读者无需更换日历订阅 URL。
- [ ] 恢复仍遵守当前外部准入及分享权益；默认链接不依赖分享权益，失去分享权益的额外链接不会因重选越权恢复。
- [ ] 失败保留该订阅和原链接，显示原因并允许按现有准入重试或再次重选；不会恢复旧班公开读取或偷偷转为新订阅。
- [ ] 重选时使用新的生命周期/目标版本，旧学期任务、前一次选择的迟到结果、重复请求以及重选期间再次切学期不能覆盖新目标或提前启用链接。
- [ ] 仅适用于本次新增来源版本的教学班订阅，不能借此恢复或迁移旧外部订阅。
- [ ] 从主人重选操作、后台结果到原 URL 读回验证地址逐字不变、成功恢复、失败继续停用、分享撤权和竞态；覆盖键盘与窄屏交互。
