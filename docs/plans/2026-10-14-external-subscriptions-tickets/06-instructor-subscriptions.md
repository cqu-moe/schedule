## What to build

沿已跑通的新外部订阅链路接入教师，补齐教师的真实搜索选择动作、目标归属和日历输出，使用现有主人状态与链接管理。

## Acceptance criteria

- [ ] 搜索结果提供稳定教师身份与必要区分信息；精确选择目标，不能用同名或第一条结果代替。
- [ ] 通过 Auth 固定教师页面动作触发采集，校验教师 ID 列表归属；只纳入确属所选教师的安排，不混入其他教师或个人课表。
- [ ] 后台首次采集、合法空结果、失败保留数据与部分导入提示在教师类型可见；目标失效时明确失败，不自动替换。
- [ ] 共用来源版本、队列运行、权限、数据质量和日历稳定身份合同，不为教师新增绕过门禁或直连旧 HTTP 的旁路。
- [ ] 接入统一 provider，使后续手动刷新与自动同步无需教师专用调度器；本任务验证首次链路，统一刷新/自动组合在相应任务及整体验收中验证。
- [ ] 补齐独立脱敏样例的目标筛选测试和 UI 交互验证；完成已登录的教师搜索、精确选择、创建和真实日历比对并记录证据。
