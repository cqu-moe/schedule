## Parent

[规格 #133](https://github.com/cqu-moe/schedule/issues/133)

## What to build

把教室的正常页面搜索、选择和课表捕获接入完整外部订阅链路，提供可区分场地的候选和只属于所选教室的日历。

## Acceptance criteria

- [ ] 候选显示足够的校区、楼栋或其他实际可用的场地区分信息；使用稳定房间 ID，不按名称模糊替换。
- [ ] 正常教室页面动作精确选择目标，响应按房间 ID 校验；混合响应不能把其他房间安排纳入。
- [ ] 异步创建至公开日历可演示；合法空、目标失效、整体失败和部分导入分别展示，错误不清空旧成功结果。
- [ ] 共用权限、来源版本、运行标识、缓存隔离和日历生成合同；可被统一手动和自动路径调用，无单独的越权或个人采集回退。
- [ ] 独立脱敏样例覆盖同名房间和多房间响应；键盘/窄屏搜索选择可用，完成已登录教室创建和日历输出比对。
