# 首页采用「校园手记」

2026-10-22，用户在三个可交互原型中选择「校园手记」，要求接入正式首页。

保留单日纸页、手写下划线、错落的日程色块，用重庆大学的课程与校园生活表达日历订阅的用途。原首页缺少产品画面；「日历画布」强调完整一周，手机需要横向浏览，因此不纳入本次实现。

正式版删除重复的三栏功能介绍、纸页上的装饰英文、重复口号和额外 CTA。保留带明确示例标识的日期切换及详情，示例不读取个人数据。登录、绑定、解绑中、加载和失败重试继续使用正式会话和认证路径。

升级 Design v1.2.0 的同版 theme/ui 包及全部 Schedule 品牌资源。蓝色 CTA 只作用于首页；订阅管理、日历及登录流程的主按钮保持设计系统的中性色。

原型选择器、模拟会话、未采用的方向与独立构建入口在接入后删除。验收记录见下方，原型验收不计为正式版验收。

## 例外与设计系统反馈

用户选定的手记插画使用首页局部的大标题比例与淡紫/杏色日程分类色，均在 `home.css` 内，不影响工作界面。未来共享包提供相应展示语义色时可替换；本次不把课程色提升为全局品牌色。

UI 1.2.0 的 `Button size="sm"` 在手机仍为 32px 高，与 44px 触控规范不符。本次页头通过业务范围的 `landing-root` 选择器扩到 44px，不修改 `.ds-*` 或依赖源码。复现：320/390px Chromium，浅深主题，首页「如何使用 / 使用指南 / 登录」；修正后八组检查均通过。此反馈尚未在 design 仓库新建 issue；共享包修复后可移除相应尺寸覆盖。

未执行完整 31 旅程 × 多浏览器矩阵、真实 CQU 账号、真机、屏幕阅读器、CI 或线上部署。保留已有 PostHog sourcemap 和 >500kB 主包构建警告。当前本地预览的 Auth 服务未连接，真实登录请使用部署环境；业务登录接线已在上述隔离 E2E 中验证。
